Notes

One attempt each

Every picture is the file the agent wrote, unedited and unpicked. Attempts that wrote nothing stay.

Four labels

The model; the effort, as the harness names it; the harness, the agent program that ran the model; the provider, where the model was served from: a subscription, the official API, or a relay that resells access.

Numbers

Six runs were timed by a script, so only they show time, tokens and cost (tokens at list price). The rest were run by hand and show a dash.

Pictures

Posters are frames at 2 seconds, rendered offline at 960×720. Hover or open a card to play the real file.

No submissions: every run is mine. New runs go through the Harbor runner in the repository. The pelican test is Simon Willison's.
