Velodrome
GitHub

A pelican riding a bicycle. Each new model, at the highest effort we can get, in a coding agent. One prompt, one attempt, unedited.

Prompt

No internet, don’t look at other local files. Create an HTML file whose content is an SVG 2D animation of a pelican riding a bicycle.

Harness

The same model in different coding agents, each at its highest effort.

Posters are the frame at 2 seconds, rendered offline at 960×720; hover or open one to play the file, its effort and provider (the model’s official API or a subscription) included. Every run is mine; the repository has each file, its record and the runner. The test is Simon Willison’s.
