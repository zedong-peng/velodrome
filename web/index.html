Velodrome

A velodrome is a cycling track. Here the riders are pelicans.

Prompt

No internet, don’t look at other local files. Create an HTML file whose content is an SVG 2D animation of a pelican riding a bicycle.

Same model, different agent

Methodology

Each run is one attempt, at the highest effort we could reach, through the model’s official API or a subscription. The agent starts in a fresh container with an empty folder and can reach only its provider. It has no browser, so it never sees what it draws. It stops on its own or at 30 minutes, and its file is shown unedited.

Runs before October 24, 2026 were made outside this container. The test is Simon Willison’s. Every file and the runner are on GitHub.
