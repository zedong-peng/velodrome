Velodrome
GitHub

A pelican riding a bicycle, animated. Simon Willison asks models for a still picture. We ask each new model, working offline in a coding agent, for an animation.

One prompt, one attempt, at the highest effort we can get. Nothing is edited.

Prompt

No internet, don’t look at other local files. Create an HTML file whose content is an SVG 2D animation of a pelican riding a bicycle.

Same model, different agent

Each at its highest effort. The agent changes the drawing, and sometimes whether there is one: Claude Haiku 5.5 drew in Claude Code and wrote nothing in OpenCode.

How a run works

  • The agent starts in a fresh container with an empty folder and can reach only its model’s provider. There is no browser, so it never sees what it draws.
  • It stops on its own, or at 30 minutes.
  • A separate container opens the file offline at 960×720. The poster is the frame at 2 seconds; hover or open a card to play the file.
  • Effort is the highest the agent offers for that model; a model without the setting runs at its default. The provider is the model’s official API or a subscription.
  • Cost is at list price; a subscription run costs nothing extra.
  • One attempt is one sample. Run it again and the drawing changes.

Runs before October 24, 2026 were made by hand or by an earlier script, outside this container, and record less. Every file, its record and the runner are in the repository. The test is Simon Willison’s.
